# 🚀 Kartik-AI

An AI-powered chatbot built to provide intelligent conversations, document analysis, and image understanding through a modern web interface.

## 🌟 Features

- 🤖 AI conversations powered by Google Gemini
- 📄 PDF upload and document analysis
- 🖼️ Image upload and image understanding
- 🧠 Conversational memory and chat sessions
- 🔐 User authentication and OTP-based verification
- 🌌 Interactive 3D space background

## 🛠️ Tech Stack

**Frontend:** React, Vite  
**Backend:** Python, FastAPI  
**AI:** Google Gemini  
**Database & Retrieval:** SQLite, FAISS  
**Deployment:** Vercel, Render

## 🌐 Live Demo

[Open Kartik-AI](https://kartik-ai-1.vercel.app/)

## 📂 Project Structure

- `frontend/` — React frontend
- `backend/` — FastAPI backend

## 🎯 Project Goal

Kartik-AI explores the integration of generative AI, full-stack web development, document processing, image understanding, and conversational memory in one application.
